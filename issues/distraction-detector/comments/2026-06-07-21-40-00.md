## Initial implementation complete

Created the detector-v0 initiative under `initiatives/detector-v0/` with full
initial code:

- `src/detector_v0/screen_capture.py` — async Wayland screenshot via `grim`
- `src/detector_v0/audio_capture.py` — async audio recording via `pw-record`
- `src/detector_v0/analyzer.py` — Pydantic AI agent with Gemini 3.1 Flash-Lite
- `src/detector_v0/tray_icon.py` — AyatanaAppIndicator3 cross icon (green/red)
- `src/detector_v0/main.py` — orchestrator loop (30s interval, 5s audio)
- `icons/green.svg`, `icons/red.svg` — cross-shaped tray icons
- `pyproject.toml` — package with `pydantic-ai[google]` dependency

Sub-issues created: capture-pipeline, ai-analysis, tray-and-runner.

### To run:
```bash
cd initiatives/detector-v0
pip install -e .
python -m detector_v0
```

- System: `grim`, `pw-record` (PipeWire), `python3-gi`, `gir1.2-ayatanaappindicator3-0.1`
